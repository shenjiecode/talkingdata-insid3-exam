# 种子选择与区域聚合中的评分差异

| 项目 | 说明 |
| --- | --- |
| 选择的考点 | 论文 §3.3–3.4 的种子选择和区域聚合。作者固定版本 `_seed_and_aggregate` 的 L336–339 用归一化 cluster 原型选择种子；L349–354 对 cluster 内的逐 patch 跨图相似度求均值；L330–334、L356–363 计算覆盖比例并判断阈值。这里考察的是两次跨图评分的区别。 |
| 题目思路 | 给出原始特征、去偏特征、聚类标签和候选 patch 掩码，要求用 NumPy 完成种子选择和聚合。特征提取、SVD 和聚类已经完成，答题者只需处理这段评分逻辑。 |
| 难点假设 | GPT-5.5 可能把两次跨图评分写成同一种计算：两处都用归一化均值原型，或两处都用逐 patch 分数均值。论文式 (9)–(13) 复用了跨图分数的记号，容易忽略作者代码在两处使用了不同的计算。 |
| 最小验证例子 | 聚合用例有 8 个 patch、3 个 cluster，参考原型是 `(0,1,0)`。cluster 1 包含两组 `(0,0.6,±0.8)`，逐 patch 分数均值为 `0.6`，候选覆盖比例为 `1/4`，图内相似度为 `1`，聚合分数为 `0.15`，低于阈值 `0.2`。另一个 4 patch 用例让两种评分选出不同的种子，数据见下表。 |
| 预期错误结果 | 聚合时先归一化均值原型，会把 cluster 1 的跨图分数算成 `1`，聚合分数变为 `0.25`，导致误选；遗漏覆盖比例会得到 `0.6`，同样误选。若选种子也用逐 patch 分数均值，4 patch 用例会误选标签 1。 |
| 如何判断 | `test_bonus_task.py` 检查聚合用例中 cluster 1 的 `cross_similarity=0.6`、`area_weights=0.25`、`combined_scores=0.15`，以及四个 patch 均未入选；种子用例检查 `seed_id=0` 及对应分数和掩码。其余测试检查特征空间、候选集合、种子权重、阈值和空候选分支。 |

设 cluster 内的去偏单位特征均值为 `m`，参考单位原型为 `p`。两种计算分别是 `m·p` 和 `(m/||m||)·p`。后一种计算去掉了均值的长度，而这个长度反映了 patch 方向的一致程度。

在 cluster 1 中，第三通道的正负分量相互抵消，均值为 `(0,0.6,0)`。归一化后它与参考完全相同，余弦相似度是 `1`；四个 patch 各自与参考的相似度却都是 `0.6`。如果只用单 patch，或让一个 cluster 内的 patch 全部相同，两种计算就会得到相同结果，测不出这个区别。

## 聚合评分用例

按行优先顺序，标签为 `[0,0,1,1,1,1,2,2]`，网格为 `2×4`。

| cluster | 原始 patch | 去偏 patch | 候选覆盖 | 跨图分数 | 图内分数 | 最终权重 | 聚合分数 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 0 | 两个 `(0,1,0)` | 同原始 | 1/2 | 1 | 1 | 1（种子） | 1 |
| 1 | 两组 `(0,0.6,±0.8)` | 同原始 | 1/4 | 0.6 | 1 | 0.25 | 0.15 |
| 2 | 两个 `(√3/2,0.5,0)` | 两个 `(0,1,0)` | 1/2 | 1 | 0.5 | 0.5 | 0.25 |

对原始特征去掉第一通道并重新归一化，就能得到表中的去偏特征。三个 cluster 的去偏均值原型都指向参考，按题面的同分规则选标签 0 为种子。阈值为 `0.2` 时，选中标签 0 和 2；cluster 2 中未被候选掩码标记的 patch 也会随整个 cluster 入选。

测试还检查了几处相关计算：

- 使用去偏特征计算图内相似度：cluster 2 的图内分数会从 `0.5` 变成 `1`。
- 没有把种子的覆盖权重设为 1：cluster 0 的权重会停留在 `0.5`。
- 在所有 cluster 中选择种子：第二个例子中不属于候选集合的 cluster 0 得分最高，但正确种子应为 cluster 1。
- 把作者的 `>` 改成 `>=`，或无条件保留种子：阈值边界例子会失败。

论文式 (14) 写了并入种子和 `≥α`。固定版本代码 L358–363 只修改种子权重，随后对所有 cluster 使用 `> merge_threshold`，没有单独把种子加回掩码。题面已说明按该代码版本实现，阈值测试也按这段代码判断。

## 种子评分用例

网格为 `1×4`，标签为 `[0,0,1,1]`，全部 patch 都是候选。原始特征与去偏特征相同，参考原型为 `(0,1,0)`。

| cluster | 两个 patch | 归一化均值原型的种子分数 | 逐 patch 分数均值 |
| --- | --- | --- | --- |
| 0 | `(0,0.6,0.8)`、`(0,0.6,-0.8)` | 1 | 0.6 |
| 1 | 两个 `(0,0.8,0.6)` | 0.8 | 0.8 |

正确种子是标签 0，两个 cluster 的聚合分数为 `[0.6,0.64]`。阈值为 `0.5` 时，四个 patch 都入选。若按逐 patch 分数均值选种子，会选中标签 1，聚合分数变为 `[0.48,0.8]`，标签 0 的两个 patch 被排除。

## 运行测试

将模型答案放进 `src/insid3_bonus.py`，运行 `python -m pytest -q bonus/test_bonus_task.py`。
本仓库不附模型待写的答案文件；尚未放入答案时，运行加分测试会报缺少文件。
默认 `python -m pytest -q` 只运行第一题，配置见 `pytest.ini`。

也可以用环境变量 `INSID3_BONUS_SOLUTION` 指定仓库外待测 `.py` 文件的绝对路径；不设置时使用题面约定的位置。
